# Luxury Golf Resort — Sunrise Pitch Frames

Portable storyboard project for a 16:9 broadcast advertisement pitch.

`project.json` is the source of truth. The sequence is currently at intake (`proposed`); planning will define the six stable frame records and prompt handoff.

## Creative constants

- Sunrise continuity with warm directional light.
- One golfer and one caddie only.
- Premium, controlled commercial realism.
- Wide establishers transition into tactile intimate details.
- Emerald fairway, restrained luxury palette, consistent walking direction.
